# The Physics Notebook

A free GitHub Pages website with equally prominent Science and Journal sections.

## Publish
In the GitHub repository, go to Settings → Pages. Under Build and deployment, choose Deploy from a branch, main, /(root), and Save. Your site will appear at https://shangoyal.github.io.

## Add an article
Edit script.js. Duplicate a post object in the posts array and give it a unique slug, a section of science or journal, title, date, excerpt and content. Commit the change to publish it.

## Equations
MathJax supports inline LaTeX using backslash-parentheses and display LaTeX using backslash-square-brackets.

The starter articles and About page are placeholders; replace them with your own writing.
